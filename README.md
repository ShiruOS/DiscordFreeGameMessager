# DiscordFreeGameMessager
It automatically sends free game news to discord channel using discord webhooks
Fires using Git-Hub Actions everyday at midnight
Keeps data in the cloud DB

## Setting up
This sections covers setting up this project on your github actions
You will need
```CRASH_BOY```
```DISCORD_WEBHOOK_URL```	
```NEWS_API```(from www.gamerpower.com)
```SUPABASE_KEY```
```SUPABASE_URL	```
```TABLE```
Push this in you project's secret available from the project setting
